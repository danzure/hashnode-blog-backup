Welcome to this week’s atozazure weekly wrap for the 16th October 2026. Below are all the key platform changes, additions and retirements for the past week.

## Compute & Containers

*   **Multi-NIC Support on AKS Powered by DRANET** *(In Preview)*  
    Cluster operators can now configure node pools with multiple secondary network interfaces and utilise the managed Dynamic Resource Allocation Network (DRANET) driver to assign dedicated NICs directly into a pod's network namespace. This provides strict network-plane isolation and deterministic throughput for high-performance workloads without custom CNI plugins in **Azure Kubernetes Service (AKS)**.
    
*   **Managed StandardV2 NAT Gateway Support in AKS** *(Generally Available)*  
    Starting from API version `2026-06-01`, new clusters configured with the `managedNATGateway` outbound type default to deploying a zone-redundant StandardV2 NAT Gateway in supported regions. This architectural upgrade delivers higher outbound throughput, zone resiliency by default, and IPv6 egress support for **Azure Kubernetes Service (AKS)**.
    
*   **Support for Java 8, 11, and 17 Ending on App Service** *(Retiring)*  
    Microsoft has announced that runtime support for Java 8, Java 11, and Java 17 will formally end on 1st September 2027, after which hosted workloads will no longer receive security patches or technical support. Engineering teams must schedule application runtime upgrades to newer Long-Term Support (LTS) Java versions on **Azure App Service**.
    
*   **Extended Security Updates (ESU) for Windows Server 2012 and 2012 R2 Concluded** *(Retired)*  
    As of 13th October 2026, the three-year Extended Security Update programme for Windows Server 2012 and 2012 R2 has officially ended, terminating all remaining security patching for legacy instances. Administrators must perform in-place upgrades or migrate remaining legacy workloads to modern operating system releases on **Azure Virtual Machines** and **Azure Arc-enabled Servers**.
    

## AI & Developer Tooling

*   **Azure MCP Server 3.0 Stable Release** *(Generally Available)*  
    The third major release of the Model Context Protocol (MCP) server introduces expanded AI agent toolsets for Terraform, backup verification, disaster recovery, and 55 site reliability engineering (SRE) commands alongside hardened security defaults for newly provisioned resources. This enables governed, automated operational diagnostics and infrastructure-as-code workflows across **Azure SRE Agent**, **Azure Backup**, and **GitHub Copilot in Azure**.
    
*   **Azure Deployment Environments Retirement Notice** *(Retiring)*  
    Azure Deployment Environments will officially retire on 22nd February 2027, from which date all environment creation, deployment, and write operations will be blocked. Platform engineering teams must transition templated self-service infrastructure workflows directly to Bicep, ARM templates, Azure Verified Modules, and CI/CD pipelines before the deadline in **Azure Deployment Environments**.
    
*   **Microsoft Dev Box Retirement Notice** *(Retiring)*  
    Microsoft Dev Box has entered maintenance mode with no new features planned ahead of its final retirement on 18th September 2028. Organisations utilising cloud-hosted developer workstations must plan migrations, policy recreation, and workload transitions toward **Windows 365** prior to service deallocation.
    

## Networking & Security

*   **WAF Exceptions on Application Gateway and Front Door** *(Generally Available)*  
    Next-generation Web Application Firewall (WAF) policies using CRS 3.2 or DRS 2.1 and later now support up to 60 rule exceptions matching request URIs, remote IP addresses, or HTTP headers. Unlike standard exclusions that only omit a single attribute, exceptions bypass evaluation across specific rules, rule groups, or entire managed rule sets, reducing false positives for trusted traffic in **Azure Web Application Firewall**, **Azure Application Gateway**, and **Azure Front Door**.
    
*   **Key Vault Secrets Provider Extension for Azure Arc-Enabled Kubernetes Retirement** *(Retiring)*  
    The Key Vault Secrets Provider extension for Arc-enabled Kubernetes clusters is scheduled for retirement in October 2027. Cloud security architects should evaluate alternative secret synchronisation mechanisms and update cluster secret management patterns across **Azure Key Vault** and **Azure Arc-enabled Kubernetes**.
    

## Databases & Storage

*   **Azure HorizonDB Regional Expansion** *(In Preview)*  
    Microsoft's cloud-native, scalable PostgreSQL database service has expanded its public preview footprint into additional global Azure regions. This enables lower-latency data residency and broader regional availability for high-scale transactional workloads running on **Azure HorizonDB**.
    
*   **Always Encrypted with Intel SGX Enclaves in Azure SQL Database Retirement** *(Retiring)*  
    Hardware-enforced Intel SGX enclave support for Always Encrypted workloads will be retired on 31st October 2027 as legacy confidential computing hardware is phased out. Database administrators must migrate confidential query processing workloads to Virtualisation-based Security (VBS) enclaves in **Azure SQL Database**.
    

## Governance, Hybrid & Management

*   **Windows Admin Center for Azure Arc-Enabled Servers** *(Generally Available)*  
    A native, one-click portal integration now provides granular server administration, certificate inspection, performance monitoring, PowerShell execution, and in-browser RDP connectivity for hybrid machines without requiring public IP addresses, VPNs, or inbound firewall ports. All management traffic is encrypted over the existing Arc agent channel and governed via Microsoft Entra ID and Azure RBAC on **Azure Arc-enabled Servers**.
    
*   **Azure Arc Multicloud Connector for Kubernetes Clusters** *(In Preview)*  
    The new Multicloud Connector automatically discovers and onboards external Amazon EKS and Google GKE clusters into Azure. This streamlines multi-cloud inventory discovery and enforces unified security, observability, and policy compliance within **Azure Arc**.
    
*   **Azure Site Recovery Support for Arc-Enabled VMware VMs and Physical Servers** *(Generally Available)*  
    Azure Site Recovery now natively detects and preserves existing Azure Arc agent configurations when enabling disaster recovery replication for Windows VMware virtual machines and on-premises physical servers. This eliminates agent compatibility conflicts and ensures uninterrupted hybrid governance and monitoring across **Azure Site Recovery** and **Azure Arc**.
    
*   **Noise Reduction in Azure Deployment Stacks What-If** *(Generally Available)*  
    Enhancements to the What-If evaluation engine filter out false-positive property drift and non-impactful noise during pre-deployment validation. This improves change prediction accuracy and reduces manual code-review overhead for infrastructure-as-code deployments using **Azure Deployment Stacks**.
